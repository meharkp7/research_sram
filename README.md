# Differential Leakage Framework for SRAM Security

This repository contains the implementation, simulations, datasets, and documentation for the research project:

"Unified Differential Leakage Framework for SRAM-Based Counterfeit Detection and Digital Tattoo Authentication"

## Objectives

- Design and characterize a baseline 6T SRAM cell
- Model transistor aging mechanisms
- Develop a differential leakage signature framework
- Implement counterfeit chip detection
- Implement digital tattoo generation
- Validate using machine learning and deep learning
- Evaluate robustness against process, voltage, and temperature variations

## Technology Stack

- SKY130A PDK
- ngspice
- xschem
- Python
- Docker (IIC-OSIC-TOOLS)
